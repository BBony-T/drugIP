# 이벤트 카드 일러스트 에셋

이 폴더의 `event.01.png`부터 `event.12.png`까지가 이벤트 카드 앞면에 합성되는 자체 제작 일러스트입니다.

- 투명 배경 PNG를 사용합니다.
- 그림 안에는 제목, 효과 문구, 로고를 넣지 않습니다. 이 요소들은 카드 생성기가 별도로 배치합니다.
- 같은 파일명으로 교체한 뒤 `tools/create_cards.py`를 실행하면 고정된 일러스트 영역 안에서 비율을 유지해 다시 배치됩니다.
- 카드 규격과 문구 영역을 지키기 위해 생성기는 일러스트를 `500 × 330px` 영역 안에 맞춥니다.
